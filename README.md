First project for The Odin Project. This is a grouping of HTML pages, one index and three separate recipes, each linking back to the index. Photos of each item provided, with cited photo credits.

I felt like this project was good to learn the basics of HTML. Learning proper pathing to link back to the index page, making sure the img sources were correctly placed, and making sure that the index paths to the correct pages. Also starting to learn correct element syntax was also helpful. While it was fairly straigtforward, I still found it challenging enough to expand my knowledge.
